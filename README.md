# 링의 왕 🥊

설치 없이 브라우저에서 하는 1인칭 3D 복싱 게임. **읽고, 피하고, 때려라!**
초등학교 6학년을 위해 모든 글자를 쉬운 한국어로 만들었다. 그림·소리·음악은 외부 파일 없이 전부 코드로 만들었다.

## 실행 방법
**가장 쉬운 방법 (Windows):** 폴더의 `게임 실행.bat`을 더블클릭한다. 처음엔 필요한 것을 설치하고, 게임을 만든 뒤 서버를 켜고 브라우저(http://localhost:3000)를 연다. 온라인 1:1도 된다.

직접 실행할 때는 Node.js 20 이상이 필요하다. (PowerShell에서 `npm`이 실행 정책 때문에 막히면 `npm.cmd`로 입력한다.)

```bash
npm install
```

```bash
npm run play
```
브라우저에서 http://localhost:3000 을 연다. (게임 + 온라인 대전 서버)

| 명령 | 하는 일 |
|---|---|
| `npm run play` | 빌드 후 게임 서버 켜기 (온라인 1:1 포함, 포트 3000) |
| `npm run dev` | 개발 서버 (5173, 온라인은 3000번 서버가 따로 켜져 있어야 함) |
| `npm run build` | `dist/`에 정적 파일 만들기 |
| `npm start` | 빌드 결과를 `server.mjs`로 내보내기 (PORT 환경변수, `/health`, WebSocket `/ws`) |
| `npm test` | 자동 테스트 80개 (`node --test`) |
| `npm run balance` | 봇 자동 플레이 균형 검사 (결과 표) |
| `npm run shots` | 실제 브라우저로 처음부터 결과 화면까지 진행하며 스크린샷 (개발 서버를 켠 뒤, PC에 Chrome 또는 Edge 필요) |

## 온라인 1:1
메뉴 → **온라인 1:1** (또는 체육관의 TV 모니터). **빠른 대전**은 기다리는 아무나와, **방 만들기**는 4자리 코드를 친구에게 알려 주고 친구가 **코드로 참가**하면 시작한다. 판정은 서버가 한다(속임수 방지). 상대의 준비 동작을 보고 피한 뒤 바로 치면 반격 + 별.

개발용 주소: `?opp=fox` (바로 그 상대와 경기), `?dev=lineup` (상대 10명 3D 모델 한 줄로 보기)

## 배포 (Render 무료)
**지금 할 수 있는 주소: https://ring-king.onrender.com** (main 브랜치에 올리면 자동으로 다시 배포됨. 무료 플랜이라 15분 동안 아무도 없으면 잠들고, 다음 접속 때 30초~1분 깨어나는 시간이 걸림)

1. 이 폴더를 GitHub 저장소로 올린다.
2. Render에서 **New → Blueprint**를 고르고 저장소를 연결하면 `render.yaml`대로 만들어진다.
   (plan free, region singapore, build `npm ci && npm run build`, start `node server.mjs`, health `/health`)
3. 직접 만들 때는 New → Web Service에서 같은 값을 넣으면 된다.

## 완성한 기능
- **전투**: 잽·스트레이트·어퍼컷·필살(별 1~3개 = 15/30/45), 좌우 피하기·숙이기·가드, 입력 버퍼 120ms, 콤보 7종(+20%), 같은 펀치 반복하면 읽힘, 텔(눈빛·준비 동작·숨소리) → 피하면 헛방 → 반격(1.5배, 어퍼 2배) → 별, 끊어치기 카운터, 페인트(가짜 텔은 눈빛 없음+능글맞은 표정+숨소리 없음), 스태미나·가드 게이지·숨 고르기·가드 깨짐, 다운·10카운트·일어나기 연타, TKO·KO·심판 3명 판정, 히트스톱·흔들림·줌·슬로모션·만화 글씨
- **링 안 걷기(WASD)**: 넓힌 링(8.4m) 안에서 나와 상대가 실제 위치를 갖는다. 앞·뒤·옆걸음, 옆걸음은 상대 주위를 돎, 상대는 걸어서 따라옴, 로프·코너에 막힘, 멀면 서로 펀치가 안 닿음
- **상대 10명**: 각자 체형·머리 모양·색·표정·전용 동작이 다른 3D 카툰 캐릭터. 페이즈 전환(빨개짐·음악·조명), 위치별 공격 방향, 페인트, 클린치, 습관 학습, 받아치기, 지구력 저하, 3페이즈 챔피언(5라운드)
- **3D 연출**: Three.js 툰 셰이딩 + 외곽선, 대회 단계별 경기장 4곳(관중 들썩임·플래시·빛 기둥·전광판), 1인칭 카메라(피하면 화면이 기울며 빠짐), 첫 라운드 카메라 진입, 심판(다운 카운트), KO 때 카메라가 빠져나와 쓰러진 상대를 비춤, 꽃가루
- **커리어와 이야기**: 동네 리그 → 전국 대회 → 월드 그랑프리 → 타이틀전 → 엔딩·크레딧, 상대 소개(3D), 컷신 9개, 코치 문철 할아버지(경기 전 힌트·라운드 사이 조언·패배 후 격려), 라이벌 카이
- **3D 체육관 허브**: 벽돌·들보·조명·햇살·포스터가 있는 체육관을 걸어 다니며, 1인칭 장갑으로 샌드백·스피드백을 직접 치고, 이긴 상대들과 이야기하고, 링·훈련·상점·트로피·화이트보드·사물함·코치·문으로 이동
- **훈련 캠프**: 샌드백(콤보), 미트 치기(리듬), 피하기 훈련(다음 상대 텔 + 안내), 줄넘기
- **상점·꾸미기**: 장갑(1인칭에 보임)·트렁크·신발·입장 음악·입장 연출·링 바닥, 능력치 영향 없음, 현금·광고·뽑기 없음
- **도전 과제 34개**, 기록 화면
- **클리어 후**: 챔피언 방어전, 보스 러시, 타임 어택, 마지막 KO 다시 보기(결정적 리플레이)
- **튜토리얼** 7단계(직접 해야 넘어감, 건너뛰기·다시 보기)
- **설정·접근성**: 난이도 3단계, 볼륨 2개, 흔들림 끄기, 깜빡임 줄이기, 움직임 줄이기(prefers-reduced-motion), 텔 강조(화살표·방패 모양), 키 바꾸기, 화질, 터치 버튼 크기
- **저장**: localStorage, 버전 3 + 마이그레이션, 저장 실패해도 진행(“저장 안 됨” 표시), 텍스트 내보내기/가져오기, 초기화
- **소리**: Web Audio 효과음 20여 종 + 코드로 작곡한 음악 18곡(대회별·보스 페이즈·체력 낮을 때 긴박하게)

## 폴더 구조
```
index.html, server.mjs, render.yaml, vite.config.js
src/
  main.js            시작·화면 전환·커리어 흐름
  config.js          모든 기본 수치(한 곳)
  save.js            저장·마이그레이션·내보내기
  game/              로직(화면·소리와 무관, Node에서 돌아감)
    fight.js player.js opponent.js combat.js scoring.js career.js replay.js rng.js inputBits.js
  data/              상대 10명(opponents/), 콤보, 대사·컷신, 상점, 도전 과제
  render/            2D(HUD, 효과, 초상화, 표정), 키프레임 동작 데이터(anims.js), 뼈대·보간(rig.js)
  render3d/          3D(무대, 경기장, 캐릭터, 1인칭, 경기 화면, 툰 셰이딩)
  audio/             sfx.js(효과음), music.js(음악)
  input/             keyboard, gamepad, touch → actions(하나의 "행동 입력")
  screens/           각 화면
tests/               자동 테스트
tools/               balance-sim.mjs, bots.mjs, screenshots.mjs, shot.mjs
```
- 로직은 화면과 완전히 분리되어 있다. 60Hz 고정 간격, 시드 난수, 프레임마다 숫자 하나(비트)짜리 입력 → 같은 시드·입력이면 같은 결과(리플레이, 나중에 온라인 대전에도 쓸 수 있는 구조).

- **균형 검사**: [BALANCE.md](BALANCE.md) — 완벽 봇 10명 전승, 연타 봇 3번부터 0%, 보통 봇 100%→35%
- **실제 화면**: Playwright(설치된 Chrome)로 PC 키보드 전체 흐름과 모바일 가로·세로 터치를 진행하며 `screenshots/`에 저장, 콘솔 에러 확인

## 확인하지 못한 것 (솔직하게)
- **실제 기기 성능**: 오래된 크롬북·보급형 태블릿에서 50fps가 나오는지 재 보지 못했다. 이 PC의 헤드리스 브라우저(소프트웨어 WebGL)에서만 돌려 봤다. 느리면 "자동 화질"이 해상도와 관중 수를 줄이도록 해 두었다.
- **소리**: 효과음·음악이 콘솔 에러 없이 재생되는 것만 확인했고, 귀로 듣고 음색을 다듬지는 못했다.
- **게임패드**: 표준 Gamepad API 배치로 코드를 짰지만 실제 패드를 꽂아 시험하지 못했다.
- **실제 아이들 플레이 테스트**: 하지 못했다. 난이도는 봇 시뮬레이션으로만 맞췄다. 어렵다면 `src/config.js`의 `hpScale`, 상대 파일의 `tellScale`·`idleBlock`부터 조정하면 된다.
- 구글 폰트는 인터넷이 있을 때만 불러온다(없으면 기본 글꼴로 깨지지 않게 표시).
